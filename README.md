# 🏡 MakersBnB (ASP.NET / C# Edition)

Thia MakersBnB project is a database‑backed web application rebuilt in **C# and ASP.NET MVC** as part of the Makers Academy curriculum. It mirrors the functionality of the original Python/Flask version, but re‑implements everything using the .NET ecosystem — including models, controllers, views, migrations, and automated testing.

This project focuses on learning how to structure a full‑stack web application in C#, work with PostgreSQL through Entity Framework Core, and build confidence with MVC patterns, routing, and server‑side rendering.

---

## ✨ Features

- Browse available spaces  
- Leave reviews for spaces  
- Reviews automatically store the date using **UTC timestamps**  
- Clean, responsive UI built with Bootstrap  
- Contact and Team pages with custom styling  
- MVC architecture (Models, Views, Controllers)  
- Database migrations using Entity Framework Core  
- Unit tests with **NUnit**  
- Feature tests with **Playwright**

---

## 🎯 Learning Objectives

This project demonstrates:

- Building a full MVC web app in **C# / ASP.NET**  
- Designing and interacting with a PostgreSQL database  
- Writing automated tests (NUnit + Playwright)  
- Using Entity Framework Core for models, migrations, and queries  
- Structuring clean controllers and views  
- Handling routing & form submissions  
- Managing schema changes and debugging database issues  
- Re‑implementing a Python/Flask project in a new language and framework
